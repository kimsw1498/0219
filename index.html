01. 프롬프트의 3가지 유형
1. 서술형

맥락과 배경을 설명하여 AI가 상황을 이해하도록 유도
(재사용 여부 : 낮음, 유연성 : 높음)

무역 전문가 페르소나
당신은 10년 경력의 무역 전문가입니다. 중소기업 수출 담당자가 HS code를 처음 배우는 상황입니다. 이 사람에게 HS code의 개념과 중요성을 설명해주세요.
2. 지침형

단계별 절차나 명확한 규칙을 제시하여 원하는 출력을 유도
(재사용 여부 : 중간, 유연성 : 중간)

파이썬 작성 규칙
다음 규칙에 따라 파이썬 코드를 작성하세요.
1) 함수명은 snake_case로 작성 2) 각 함수의 docstring을 포함 3) 예외 처리 반드시 포함 (try, except) 4) 결과는 Jason 형식으로 반환
3. 함수형

입력값과 출력값을 명확히 정의하여 일관된 결과를 생성, 구조
(재사용 여부 : 높음, 유연성 : 낮음, 토큰이 덜 낭비됨, 전문성 높음)

관세율 조회 구조
입력 : {product_name}, {hs_code}, {country}
처리 : 해당 국가의 관세율 및 수입 규제 조회
출력 : {“관세율” : “”, “규제사항” : [], “필요서류” : [] }

03. 페르소나 패턴 (act as)
좋은 페르소나 4요소

1.당신은 [역할]입니다
2.[경력/배경]을 가지고 있으며
3.[전문 분야]에 특화되어 있습니다
4.[말투/태도]로 응답하세요

관세사 페르소나
“당신은 20년 경력의 관세사입니다. FTA협정세율과 원산지 규정의 전문가로 중소기업 무역 담당자에게 복잡한 내용을 쉽고 실용적으로 설명하는 것이 특기입니다.”
멀티 페르소나 기법

한 번에 여러 개의 페르소나를 줄 수 있음

전문가 전략 분석
다음 3명의 전문가 입장에서 동남아 수출 전략을 분석하세요
김부장(현장 중심), 박이사(데이터 중심), 박대표(속도 중시).
각자의 관점에서 찬반 의견 제시.
04. 마크다운 프롬포트 작성법
핵심 요소 6가지

# : 헤더, """ : 코드블럭, > : 인용문, - : 목록, | : 표, ** : 굵게

실습 예제 (FTA 분석)
#역할: 중소기업 수출 컨설턴트
#작업: 아래 수출 품목 FTA 적용 분석
"""품목명: 스테인리스 주방 용품"""
>확실하지 않은 세율은 반드시 “세관 확인 필요”로 표기
05. 표현 강도와 중요도 조절
강도 4단계

1단계(권장) / 2단계(일반) / 3단계(강조) / 4단계(절대)

우선순위 예시
🔴최우선(절대): 개인 정보 출력 금지, 사실과 다른 내용 생성 금지
🟡중요(일반): 답변 500자 이내, 전문 용어 괄호 설명
🔵선택(권장 조건):가능하면 실제 사례를 포함, 표나 목록을 활용하면 더 좋다
네거티브 프롬프팅: 배경지식은 포함하지 말 것
06. 톤(말투) 지정 기법
다양한 톤 활용

유머러스한, 감정적인, 따뜻한, 아이러니한, 로맨틱한 등

보고서 작성 지시
요약 섹션: 임원 보고용(3줄 이내, 숫자 중심, 공식적 톤)
본문 섹션: 실무자용(단계별 설명, 구체적 톤)
결론 섹션: 전체 독자용(행동 유도, 적극적 톤)
07. 대안 접근법 패턴
패턴 유형

단순 나열형, 축 기반 비교형, 상황별 분기형, 역발상 대안형

통관 지연 역발상
문제: 수입 통관 처리 시간이 너무 오래 걸린다.
“하지 않는” 선택지와 “문제 자체를 재정의”하는 방법도 포함하여 총 다섯가지 제시하세요.
08. 이용자 페르소나 패턴
설계 체크리스트

직업, 사전 지식 수준, 실행 목표, 현재 상태(급함/여유), 우려 사항

중소기업 대표 맞춤
이용자: 수출 처음인 대표(제조업). 바빠서 긴 글을 읽지 않음.
지시: 첫 수출 준비 3단계 설명해줘. 전문 용어 최소화, 각 단계 세 줄 이내 작성.
09. 레시피 패턴 (작업 단계 받기)
레시피 구성

STEP번호, 할 일, 소요시간, 완료기준, 주의사항

파이썬 자동화
#목표: Python 초보자를 위한 HS code 자동 분류 프로그램 만들기
#요청: 목표 달성을 위한 단계별 레시피를 작성하세요.
10. 뒤집힌 상호작용 패턴
방법

1.질문 먼저, 답은 나중 2.한번에 하나씩 질문

수출 제안서 작성
“바로 작성하지 말고, 먼저 아래 항목들을 질문해서 제 답변을 모두 수집한 후 작성하세요: 제품 정보, 타겟 바이어, 핵심 강점, 가격 정책, 납기 조건.”
11. 인지 검증자 패턴
작동 원리

복잡한 질문 입력 -> 하위 질문 분해 -> 순서대로 검증 -> 검증된 답 통합

베트남 법인 설립 분석
“아래 질문에 바로 답하지 말고 먼저 필요한 하위 질문 목록을 만들고 각 하위 질문에 순서대로 답한 뒤 최종 통합 답변을 제시하세요: 우리 회사가 베트남에 생산 법인을 설립하면 유리한가?”
