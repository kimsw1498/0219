01. 프롬프트의 3가지 유형
1. 서술형

맥락과 배경을 설명하여 AI가 상황을 이해하도록 유도
(재사용 여부 : 낮음, 유연성 : 높음)

무역 전문가 페르소나
당신은 10년 경력의 무역 전문가입니다. 중소기업 수출 담당자가 HS code를 처음 배우는 상황입니다. 이 사람에게 HS code의 개념과 중요성을 설명해주세요.
2. 지침형

단계별 절차나 명확한 규칙을 제시하여 원하는 출력을 유도
(재사용 여부 : 중간, 유연성 : 중간)

파이썬 작성 규칙
다음 규칙에 따라 파이썬 코드를 작성하세요.
1) 함수명은 snake_case로 작성 2) 각 함수의 docstring을 포함 3) 예외 처리 반드시 포함 (try, except) 4) 결과는 Jason 형식으로 반환
3. 함수형

입력값과 출력값을 명확히 정의하여 일관된 결과를 생성, 구조
(재사용 여부 : 높음, 유연성 : 낮음, 토큰이 덜 낭비됨, 전문성 높음)

관세율 조회 구조
입력 : {product_name}, {hs_code}, {country}
처리 : 해당 국가의 관세율 및 수입 규제 조회
출력 : {“관세율” : “”, “규제사항” : [], “필요서류” : [] }

16. 리플렉션 패턴

26. 다중 관점 기법 : 여러 관점으로 보기
핵심 원리

문화권별 분석 포함, 관점의 충돌/동의/보완을 통해 완전한 해결책 발견

- 전문가: 실용성↑ 감성↓
- 사용자: 공감↑ 전문성↓
- 낙관론: 가능성↑ 리스크↓
- 비관론: 리스크↑ 기회↓

5가지 분석 원칙
1. 이해관계자 차원 : 관련된 사람들의 서로 다른 입장 2. 전문 분야 차원 : 다른 학문과 직종의 시각 3. 시간 차원 : 과거 / 현재 / 미래 시각 4. 가치관 차원 : 다른 철학과 우선순위 5. 문화, 맥락 차원 : 다른 환경 배경의 시각 (나라별 분석 가능)
구현 방법론

병렬 관점, 대화 시뮬레이션, 레이어 분석

방법 1~3 프롬프트 레시피
#방법1 : 병렬 관점 소환 "아래 주제를 {N가지 관점}에서 동시에 분석하세요. 각 관점은 독립적으로 분석하되 마지막에 교차점을 찾아주세요." #방법2 : 대화 시뮬레이션 "{관점A}, {관점 B}, {관점 C}가 같은 테이블에 앉아 토론합니다. 주장, 반론, 결론을 써주세요." #방법3 : 레이어 분석 "주제를 {레이어1}에서 {레이어N}까지 쌓아가며 분석하세요. 아래 층위가 위 층위를 어떻게 규정하는지 보여주세요."
실무 예제 3가지

상세 시나리오 예시
Ex1) 중소기업 수출 자동화 시스템 도입 이해관계자 분석 (대표, 무역 팀장, 팀원, IT 외주업체) - 핵심 욕구, 핵심 공포, 겉으로 말하는 것 vs 속마음, 협상력 분석 Ex2) 5가지 전문 분야 렌즈 분석 (심리학 / 경제학 / 시스템공학 / 인류학 / 게임 디자인) - 무역팀의 자동화 도구 활용 저조 문제 분석 Ex3) 3개 시간 레이어 분석 (한국 중소기업의 무역 디지털 격차) - 레이어 1(과거), 레이어 2(현재), 레이어 3(미래) 간의 영향 관계 분석
27. 심사숙고 유도 기법 & COT

28. APE (Automatic Prompt Engineer)
마스터 프롬프트

Gems나 GPTs 제작 시 유용한 자동 생성 및 평가 시스템

APE 실행 순서 (STEP 1~4)
STEP 1 : 후보 생성 (역할부여, 단계별, 예시포함, 제약명시, 목적중심, 독자설정, 형식지정, 품질기준, 역방향, 메타지시형 등 10개) STEP 2 : 자체 평가 (명확성, 완전성, 실행가능성, 품질유도력 각 25점 / 총 100점) STEP 3 : 상위 3개 교차 최적화 및 결합 STEP 4 : 최적 프롬프트 전문 출력 및 사용 주의사항 설명
